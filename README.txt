KCCL GitHub Pages HTML Conversion

This folder contains standalone HTML versions of the uploaded PHP pages.
The full header and footer are embedded in every page, and internal PHP links have been changed to HTML links.

IMPORTANT:
1. Copy your existing `assets` folder beside these HTML files before publishing.
2. Publish from the repository root with `index.html` at the top level.
3. The contact form is intentionally disabled in this static GitHub demo because GitHub Pages does not run PHP.
4. Copyright year and experience counters are rendered for 2026 (42 years since 1984).
5. The supplied `extra.php` was a content fragment; it has been wrapped with the same header and footer as a standalone `extra.html` page.
